# Plantillas — Índice

Biblioteca de plantillas de Prompt Master (A–M). Cada plantilla vive en un archivo por categoría: lee SOLO el archivo de la plantilla elegida. Las plantillas son esqueletos: conserva únicamente las secciones que cambian el resultado y escribe las etiquetas en el idioma del prompt.

| Plantilla | Mejor para | Archivo |
|-----------|-----------|---------|
| A — Directa | Tareas simples de un paso | [templates/writing.md](templates/writing.md) |
| B — Brief de escritura | Documentos, textos de negocio, marketing, creatividad y voz de marca | [templates/writing.md](templates/writing.md) |
| C — Razonamiento auditable | Lógica, matemáticas, análisis, depuración, decisiones | [templates/writing.md](templates/writing.md) |
| D — Ejemplos (few-shot) | Salida estructurada consistente | [templates/writing.md](templates/writing.md) |
| E — Alcance de archivo | Cursor, Windsurf, Copilot y cualquier IA que edita código acotado | [templates/code-agents.md](templates/code-agents.md) |
| F — Agente autónomo | Devin, SWE-agent, Manus, agentes de navegador y agentes sin plantilla propia | [templates/code-agents.md](templates/code-agents.md) |
| G — Descriptor visual | Generación de imagen y video | [templates/visual.md](templates/visual.md) |
| H — Edición con referencia | Modificar una imagen existente | [templates/visual.md](templates/visual.md) |
| I — ComfyUI | Flujos de ComfyUI por nodos | [templates/visual.md](templates/visual.md) |
| J — Decompilador | Desglosar, adaptar, simplificar o dividir prompts existentes | [templates/decompiler.md](templates/decompiler.md) |
| K — Brief para Claude | Tareas complejas o agénticas en Claude y Claude Code | [templates/task-briefs.md](templates/task-briefs.md) |
| L — Brief para OpenAI | Tareas complejas en ChatGPT, Codex o la API | [templates/task-briefs.md](templates/task-briefs.md) |
| M — Prompt permanente | System prompts, GPTs, Proyectos, CLAUDE.md, AGENTS.md, reglas de Cursor y Copilot | [templates/persistent.md](templates/persistent.md) |

**Equivalencias con la v1:** A=RTF, B=CO-STAR+RISEN+CRISPE (unificadas), C=E antigua, D=F, E=G, F=H corregida, G=I, H=J, I=K, J=L, K=M, L=N. M es nueva.
